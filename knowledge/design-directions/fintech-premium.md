# Visual Direction: Premium / Fintech

- **Best for:** Personal finance, investing, banking, crypto wallets, SaaS analytics, executive dashboards.
- **Palette:** Deep obsidian (`#090B10`) or crisp architectural alabaster (`#F8FAFC`), razor-thin hairline borders, cool slate secondary copy, surgical emerald/amber semantic deltas, and a single authoritative brand tint.
- **Typography:** Ultra-crisp sans with strict `tabular-nums` on every currency figure, percentage, and delta; clean hierarchy between primary balance and secondary metadata.
- **Layout:** Clean grouped inset lists (iOS-style), focal balance hero without clutter, compact spark/ring indicators only where data earns them, instant scanability.
- **Motion:** Precise, high-damping `stiff`/`snappy` springs, smooth numeric counters (`AnimatedCounter`), instant haptic confirmation on money/trade actions.
- **Avoid:** Cartoonish illustrations, playful bounce physics, noisy multi-color gradients, ambiguous primary actions.
