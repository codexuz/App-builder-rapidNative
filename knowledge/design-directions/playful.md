# Visual Direction: Playful / Gamified

- **Best for:** Language learning, habit games, fitness adventures, student apps, creative clubs.
- **Palette:** Sunlit warm canvas (`#F5EFE4`) or rich twilight dark (`#0E1220`), high-contrast ink, saturated region/category accents (teal, coral, gold, indigo) reserved for rewards, streaks, and interactive targets.
- **Typography:** Bold, friendly rounded/geometric headings with clear weight steps and tabular numeric counters for XP, streaks, and scores.
- **Layout:** Visual journeys, progress paths, illustrated destination headers, tactile 3D-bezel primary CTAs, clear celebration moments.
- **Motion:** Expressive `bouncy` / `snappy` springs, pulsing active targets, animated progress rings/bars, celebratory counters with native haptics.
- **Avoid:** Preschool clutter for teen/adult audiences, low-contrast pastel text on bright fills, emoji used in place of real icons.
